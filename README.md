# Orbitarium

Orbitarium is an interactive space exploration museum built as a frontend-only website. Visitors can explore planets, missions, rockets, astronauts, black holes, galaxies, space terminology, and astronomy concepts through animated and expandable exhibits.

## Features

- Animated hero and starfield background
- Interactive solar system with clickable planets
- Detailed planet panels with facts, atmosphere, gravity, temperature, exploration history, discoveries, and open science questions
- Searchable cosmic atlas with category filters
- Expandable exhibit notes for deeper learning
- Planet comparison console
- Mission timeline and mission dossier cards
- Rocket launch exhibit
- Astronaut profile section
- Black hole and galaxy exhibits
- Expandable space glossary
- Mission specialist quiz
- Responsive design for desktop and mobile

## Tech Stack

- HTML
- CSS
- JavaScript

No backend, framework, database, or build step is required.

## Getting Started

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 4174
```

Then visit:

```text
http://localhost:4174
```

## Content Sources

The educational content is based on public space science knowledge and NASA reference material, including information about the solar system, planets, missions, black holes, galaxies, and telescopes.
